# 🩺 MedExit — Medical Exit Exam Prep

A Progressive Web App (PWA) for medical exit exam preparation with MCQs, Q&A, Flashcards, and Mnemonics.

## 🌟 Features

- 📋 **MCQs** — Interactive multiple choice questions with instant feedback
- 💬 **Q&A** — Expandable question and answer cards
- 🎴 **Flashcards** — Flip cards for active recall
- 🧠 **Mnemonics** — Memory aids for complex topics
- 🌐 **Multi-language UI** — English, Pashto (پښتو), and Dari (دری)
- ➡️ **Auto RTL** — Pashto/Dari content automatically displays right-to-left
- 🌙 **Dark/Light Theme** — Toggle between themes
- 📱 **PWA** — Install to home screen for app-like experience
- 📴 **Offline Support** — Works without internet after first load
- 🔄 **Auto-refresh** — Pulls latest content from JSON file
